## 🚀 Featured Project

### [Retention Revenue Intelligence](https://github.com/AchalaJain/retention-revenue-intelligence)

> End-to-end churn prediction and CLV scoring system identifying **₹3,33,912
> in annual recoverable revenue** across 7,032 SaaS customers.

**What I built:**
- 8 SQL queries surfacing churn patterns and revenue risk across customer segments
- Logistic Regression model (AUC 0.835) outperforming Random Forest on churned
  class recall — catching 34 additional at-risk customers per scoring cycle
- CLV scoring system ranking every customer by revenue-weighted churn risk
- Two-page Power BI dashboard with retention priority matrix and action plan

**Stack:** Python · SQL · Scikit-learn · Power BI · SQLite · Google Colab
